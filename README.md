# Forkistry

Каталог пошаговых рецептов с режимом готовки и таймерами на каждом шаге. Учебный проект по дисциплине «Тенденции проектирования графических пользовательских интерфейсов» (РТУ МИРЭА, ТКМО-02-25, Буряков А. И.).

Сайт: https://forkistry.albania2win.ru

## Что умеет

- каталог с поиском по названию и продуктам, фильтрами по категории, технике, времени, сложности и калорийности, сортировкой;
- страница рецепта с пересчётом ингредиентов под число порций, калорийностью на порцию или на 100 г, лайками и избранным;
- режим готовки в двух вариантах для исследования: А — один шаг на экране, Б — список шагов; у каждого шага свой таймер со звуком и вибрацией;
- регистрация и вход по email, профиль, создание, редактирование и удаление своих рецептов;
- адаптивная вёрстка: телефон, планшет и десктоп.

## Стек

React 18, Vite 8, React Router 6, CSS Modules, lucide-react; бэкенд — PocketBase; тесты — Vitest, React Testing Library, MSW.

## Запуск локально

```bash
npm install
# PocketBase 0.40.6 для своей ОС: https://github.com/pocketbase/pocketbase/releases → распаковать в .pocketbase/
npm run pb      # PocketBase на 127.0.0.1:8090, применит схему и демо-рецепты
npm run dev     # фронтенд на http://127.0.0.1:5173
```

| Команда | Что делает |
| --- | --- |
| `npm test` | 93 автотеста |
| `npm run build` | production-сборка в `dist/` |
| `npm run seed` | пересобрать миграцию с демо-рецептами из `src/data/mockRecipes.js` |
| `npm run deploy` | тесты, сборка и выкладка на сервер |

## Структура

```
src/
  api/          REST-клиент PocketBase: recipes, auth, favorites, votes
  components/   компоненты дизайн-системы (одна папка — компонент + CSS-модуль)
  context/      Auth, Favorites, Filters, Settings
  data/         справочник продуктов, категории, демо-рецепты
  hooks/        useAsync, useForm, useStepTimers, useGoBack, useWakeLock
  pages/        экраны
  styles/       токены дизайн-системы и базовые стили
  test/         мок API и интеграционные тесты
pb_migrations/  схема базы и демо-данные
pb_hooks/       счётчики лайков и избранного
scripts/        seed демо-данных и выкладка на сервер
```
